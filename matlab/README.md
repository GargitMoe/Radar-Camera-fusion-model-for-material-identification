# MATLAB Radar Preprocessing Pipeline

This directory contains MATLAB scripts for **raw mmWave radar data processing** and **Range-Angle (RA) map generation** from the TI IWR6843 sensor used in this project.

## Pipeline Overview

```
Raw .bin (from IWR6843)
        │
        ▼
IWR6843_readDCA1000.m         ── Read raw binary → complex I/Q data
        │
        ▼
ConvertBin2ChannelData.m      ── Organize into per-channel matrices
        │
        ▼
CalculateRAmap.m              ── Range-FFT + Angle-FFT → RA map (.mat)
CalculateRAmapNew.m           ── Updated / improved version
        │
        ▼
  RA map .mat  ──▶  Python CNN (SmallRACNN)
```

### Entry Point

The fastest way to generate RA maps from raw `.bin` files:

```matlab
compute_RA_from_bin       % Main script: reads bin → saves RA map as .mat
```

## Files

| File | Description |
|------|-------------|
| `compute_RA_from_bin.m` | **Main script** — end-to-end: bin → RA map .mat |
| `IWR6843_readDCA1000.m` | Read DCA1000 raw binary data (original) |
| `IWR6843_readDCA1000_streamlined.m` | Streamlined reader variant |
| `ConvertBin2ChannelData.m` | Convert raw data to per-channel matrices |
| `CalculateRAmap.m` | Range-FFT + Angle-FFT RA map generation |
| `CalculateRAmapNew.m` | Updated RA map generation |
| `Output.m` | Output / save helper |

### Analysis Scripts (`analysis/`)

| File | Description |
|------|-------------|
| `CalculateChanFeature.m` | Channel-domain feature extraction |
| `CalculateChirpFeature.m` | Chirp-domain feature extraction |
| `CompareTimeDomain.m` | Time-domain waveform comparison |
| `EarlyLate.m` | Early-late processing analysis |

## Sensor Config (IWR6843)

| Parameter | Value |
|-----------|-------|
| Start freq | 60 GHz |
| Chirp slope | 29.982 MHz/μs |
| ADC samples | 512 |
| Sampling rate | 5 MHz |
| TX × RX | 3 × 4 (MIMO) |
| Frame period | 62 ms |

> **Note:** RA maps (.mat) generated by these scripts serve as the input to `data/dataset.py` in the Python pipeline.
